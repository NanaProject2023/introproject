Euphoria Bazaar

Euphoria Bazaar is a virtual one-stop shop designed for the modern woman, offering a curated collection of fashion and home goods. From stylish boots and jeans to elegant makeup and unique home items, Euphoria Bazaar brings everything you need into one seamless experience.

## Features

- **Boots:** Explore a variety of footwear options, from casual to elegant.
- **Jeans:** Find the perfect fit with a range of styles and washes.
- **Makeup:** Discover beauty essentials to elevate your look.
- **Home Goods:** Shop for chic home items, like leather rugs and decor.

## Getting Started

To view the project, simply visit the live site: 
https://nanaproject2023.github.io/introproject/

If you'd like to run it locally, clone the repository, install dependencies with:

```bash
npm install
```

and run it with:

```bash
npm start
```

## Tech Stack

- React.js for the front-end
- CSS for styling
- React Router for navigation
